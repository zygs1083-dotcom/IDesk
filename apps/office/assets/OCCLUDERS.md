# 第三版遮挡件：工作区 1 样板

坐标单位是原背景像素，原图 1672×941，不从第一版 scene.json 复制座位点。`assets/layout.json` 是第三版源文件；第二版 `public/layout.json`、`office-schemas.ts` 与运行时保持原样。以下读图以最近邻放大、原图像素边界为准，背景的柔边和投影不作为轮廓外沿。

## 重新生成与审图

在仓库根运行：

```sh
node apps/office/tools/occluders.mjs
node apps/office/tools/occluder-overlay.mjs /tmp/w73-review --grid
node apps/office/tools/occluder-grid.mjs /tmp/w73-grid.json
node apps/office/tools/occluder-seated.mjs /tmp/w73-review
```

overlay 的青色 1px 线是多边形，紫色横线是 baseline，黄色十字是座位落地点中心，绿色小方框是 workSpot，橙色框是文字区；区域图和全景均为 3 倍最近邻放大。栅格草稿只把多边形靠近 baseline 的 16px 带投影成障碍（baseline 在多边形下方时，把底部带平移到 baseline），并打开座位/目的地格；不是最终通行图。W73 数据暂全 `.`，W73c 必须按桌柜实际占地、过道和入口手修。

`occluders.json` 使用 TexturePacker hash：`frame` 是图集矩形，`background` 是该帧在背景的左上角；`spriteSourceSize` 从零开始，未裁掉任何包围盒内的透明边。按 id 固定顺序打包，无时间戳。像素中心按奇偶规则测试是否在多边形内，内部 RGB 原样复制、alpha=255，外部 RGBA 全零。

## 分阶段数据契约

`meeting`、`lounge`、`reception`、`spots`、`standing`、`points` 在本阶段可省略；有 `spots` 时仍要求完整八种唯一 id。W73c 补齐后由 W74 改为必填。座位、命名点、spots、站位必须落在背景内且格子可走；workSpot、counter、文字矩形也检查背景边界。zone 成员与 seat.zone 双向一致，hostZones 只引用存在的区域。

## 合成图的角色锚点

合成工具直接读取 `characters.json` 每帧的 `anchor`，贴图左上角 = 座位点 − 帧尺寸 × anchor；镜像时同时镜像横向锚点。排序始终使用座位 y。姿势锚点的数值和量法只维护在 [PROMPTS-seated.md](PROMPTS-seated.md)，本文件不再维护一份姿势偏移表。
