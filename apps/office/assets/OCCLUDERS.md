## 重新生成与审图

在仓库根运行：

```sh
node apps/office/tools/occluders.mjs
node apps/office/tools/occluder-overlay.mjs /tmp/w73-review --grid
node apps/office/tools/occluder-grid.mjs /tmp/w73-grid.json
node apps/office/tools/occluder-seated.mjs /tmp/w73-review
```

overlay 的青色 1px 线是多边形，紫色横线是 baseline，黄色十字是座位落地点中心，绿色小方框是 workSpot，橙色框是文字区；区域图和全景均为 3 倍最近邻放大。栅格草稿只把多边形靠近 baseline 的 16px 带投影成障碍（baseline 在多边形下方时，把底部带平移到 baseline），并打开座位/目的地格；不是最终通行图。W73 数据暂全 `.`，W73c 必须按桌柜实际占地、过道和入口手修。

`occluders.json` 使用 TexturePacker hash：`frame` 是图集矩形，`background` 是该帧在背景的左上角；`spriteSourceSize` 从零开始，未裁掉任何包围盒内的透明边。按 id 固定顺序打包，无时间戳。像素中心按奇偶规则测试是否在多边形内（恰好在边界上也保留），内部 RGB 原样复制、alpha=255，外部 RGBA 全零。

## 分阶段数据契约

`meeting`、`lounge`、`reception`、`spots`、`standing`、`points`、`drops` 均为必填；`spots` 要求完整八种唯一 id。座位、命名点、spots、站位必须落在背景内且格子可走；workSpot、counter、文字矩形也检查背景边界。zone 成员与 seat.zone 双向一致，hostZones 只引用存在的区域。

## 合成图的角色锚点

合成工具直接读取 `characters.json` 每帧的 `anchor`，贴图左上角 = 座位点 − 帧尺寸 × anchor；镜像时同时镜像横向锚点。排序始终使用座位 y。姿势锚点的数值和量法只维护在 [PROMPTS-seated.md](PROMPTS-seated.md)，本文件不再维护一份姿势偏移表。

### workSpot 可见性

workSpot 是坐满时可见的桌面点；卡片矩形和暖光中心都不能落在任何坐着的人的像素上。按真实角色图集的帧锚点与 mirror 合成全部座位，用 `zIndexOf` 排序扣除遮挡件盖住的像素，再逐点核对卡片外框（含描边 35×23 像素）和暖光中心。会议室从南排三人的头顶上方量取桌面空隙；休息区取茶几前缘的裸露桌面，避开花盆与书。其余工位同样检查五种智能体的 sit 与 typing 两帧，前台检查礼仪 down 的三帧。
