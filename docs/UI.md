# IDesk 界面设计语言

默认的「简洁」皮肤像一件 Apple 出的内部工具：安静、精确、有密度、没有装饰。设置可切换「卡通文具」（§7）和「像素事务所」（§8）。三套皮肤共用业务组件和功能，像素事务所有独立的视觉构图。

## 1. 气质

- **安静的底，清楚的字**。浅灰暖底色，白色面板，字是主角。颜色只用来表达状态，不用来装饰。
- **密度优先**。这是工作台，不是落地页。1920 宽一屏放下全部 6 列、每列 6 张卡；1440 宽放不下就横向滚动，不压缩卡片。
- **一次只说一件事**。每个面板一个主要动作；次要动作收进 `…` 菜单。
- **物理感**。拖动卡片有重量，落下有回弹；列表项悬停只是微微提亮，不放大、不加阴影动画。

## 2. 禁止项（去 AI 味）

- 紫色/蓝紫渐变、渐变文字、发光描边、玻璃模糊满屏。
- Emoji 当图标；图标套圆底色的"功能网格"。
- 空洞文案：「强大的」「智能的」「一站式」「✨」。标题就说名词：任务、智能体、定时、连接器。
- 假数据、假头像、假徽章。空状态就是一句话和一个动作。
- 每个卡片都带阴影、每个按钮都是胶囊、每个区块都是大圆角。
- 五颜六色的 tag。标签默认灰色，最多一个强调色。
- 动画超过 240ms；进场动画一堆元素挨个飞入。

## 3. 基础

### 颜色（CSS 变量，`apps/web/src/styles/tokens.css`）

```
--bg:          #F5F5F7      页面底
--surface:     #FFFFFF      面板、卡片
--surface-2:   #FAFAFB      列背景、输入框
--line:        rgba(0,0,0,.08)   分隔线、卡片边
--line-strong: rgba(0,0,0,.14)
--text:        #1D1D1F
--text-2:      #6E6E73      次级
--text-3:      #AEAEB2      占位、禁用
--accent:      #0A84FF      唯一的交互色（链接、主按钮、选中）
```

状态色只用于状态点、状态文字、计数，不铺底：

```
open         #8E8E93  灰
recruiting   #AF52DE  紫（唯一允许的紫，只在状态点）
assigned     #5856D6  靛
in_progress  #0A84FF  蓝
paused       #FF9500  琥珀
done         #34C759  绿
failed       #FF3B30  红
```

深色模式：`prefers-color-scheme: dark` 下整套变量翻转，底 `#000`，面板 `#1C1C1E`，线 `rgba(255,255,255,.1)`。第一版必须同时做好。

### 字体

```
font-family: -apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC",
             "Helvetica Neue", "Noto Sans SC", sans-serif;
```

不引外部字体。数字和 id 用 `font-variant-numeric: tabular-nums`。

字阶（只用这几档）：

| 用途 | 大小/行高/字重 |
| --- | --- |
| 页面标题 | 22 / 28 / 600 |
| 区块标题、列标题 | 15 / 20 / 600 |
| 正文、卡片标题 | 14 / 20 / 500 |
| 次要信息 | 13 / 18 / 400 |
| 标签、计数 | 12 / 16 / 500 |

字距：标题 `-0.01em`，其余 0。

### 间距与圆角

8pt 网格。页面边距 24，面板内边距 16，卡片内边距 12，行内元素间距 8。

圆角：卡片 10，面板 12，按钮/输入 8，标签 6，弹层 14。没有更大的。

阴影只有两级：卡片悬浮 `0 1px 2px rgba(0,0,0,.06)`；弹层 `0 8px 30px rgba(0,0,0,.12)`。静止的卡片没有阴影，靠 1px 的 `--line`。

### 图标

Lucide，`stroke-width: 1.5`，16px 行内 / 18px 按钮。一个产品一套图标。

### 动效

- 悬停、按下：120ms `ease-out`，只改颜色和不透明度。
- 展开、弹层：200ms `cubic-bezier(.2,.8,.2,1)`。
- 拖拽释放：`motion` spring `{ stiffness: 500, damping: 35 }`。
- 列表变化用 `layout` 动画让卡片滑到新位置，不闪现。
- `prefers-reduced-motion` 下全部关掉。

## 4. 布局

```
┌─ 侧栏 220 ─┬──────────── 内容 ────────────────┐
│ IDesk       │ 标题行（标题 · 筛选 · 搜索 · 主按钮）│
│ 协作台      │                                   │
│ 传递区      │                                   │
│ 自动化      │ 看板：列最小宽 260，平分剩余宽度， │
│ 智能体      │ 放不下时横向滚动                   │
│ 定时        │                                   │
│ 活动        │                                   │
│ 设置        │                                   │
│ ─────       │                                   │
│ ● 3 在线    │                                   │
└─────────────┴───────────────────────────────────┘
```

看板（协作台和自动化）：每列和看板一样高，列头固定，卡片超出列高时只在这一列里纵向滚动，卡片不能画到列的底色外面；看板本身只横向滚动。三套皮肤和手机列选择器的行为一样。

侧栏底部固定显示在线智能体数。窄于 900px 时侧栏折叠成顶部一行图标。

侧栏底部在线人数右侧一个「EN / 中」文字按钮切换语言（规则见 DESIGN §12.18）。只读访客（`GET /auth/me` 的 role 为 viewer）：侧栏底部多一个 `只读` 小标（text-secondary，line 边框，圆角 control），其余界面一样；写操作被 403 时用现有的错误提示显示「只读账号」。

## 5. 页面

### 登录 `/login`

页面正中一张 360 宽的面板：「IDesk」标题、一个密码输入框、一个「登录」主按钮。错误时输入框下一行红字「密码不对」。没有 logo、没有插画、没有副标题。任何接口返回 401 都回到这里。

### 协作台 `/desk`

列顺序：待领取 · 招募中 · 已指定 · 进行中 · 已暂停 · 已完成。
列头：状态点 + 中文名 + 计数。已完成列默认只显示最近 7 天。顶部「历史」进入 `/desk/history`，按已完成/已取消切换，服务端搜索任务ID/标题/正文/结果，每页 30 条并加载更多，点击仍用任务详情抽屉。手机协作台和自动化看板各有原生列选择器，跳到指定列，保留面板内横向滚动。

历史页筛选网址：`/desk/history` 用 `q` 保存搜索、`status=cancelled` 保存已取消；缺省、`done` 或非法状态均按已完成解释，参数重复时取首值。搜索保留原字符串，输入立即 replace 网址、清空移除 `q`，查询仍防抖200ms；切到另一状态 push 一次，重复点当前状态不新增记录。首次只按网址读取，不额外规范化导航；筛选操作规范化本页的 `q/status`（空搜索及默认状态移除），保留 `task` 与所有未知参数及重复值。本页筛选、打开/关闭详情保留 hash，详情开关只改 `task` 并 replace。刷新、直接链接及前进后退同步筛选控件与结果，过期计时器不能回写网址或恢复旧搜索。

历史查询继续服务端每页30条、按 `status/q` 分离游标与缓存；新组合从首游标开始，返回已访问组合可复用原缓存的已加载页。网址不记录游标、页数或滚动，刷新/新链接从首屏页开始。管理员与只读访客行为相同，不改变详情权限、搜索范围、排序、控件布局或密度。

卡片：

```
┌────────────────────────────┐
│ 标题（最多两行）              │
│ 修复登录页在 Safari 的闪烁    │
│                            │
│ coding · browser     ↑high  │   能力标签灰色；优先级只在 high/urgent 显示
│ ● codex@mac-mini  12 分钟前  │   负责人 + 相对时间；无负责人时显示发布者
└────────────────────────────┘
```

已指定列中由交接而来的卡片多一行 `← codex@mac-mini 交接`。招募中卡片显示 `2 / 3 已加入`。进行中的卡片，租约剩余不足 2 分钟时时间变橙色。被依赖阻塞的卡片（`blockedBy` 里还有未完成的）标题前一个 lucide `Lock` 图标（16px，text-3）加数字 n（未完成的阻塞数），卡片本身仍可拖，放下时按状态机的 409 原因抖动并提示。

头部：搜索框右侧一个分段控件「平铺 | 按主机」。分组先读网址 `group=flat|host`；首次缺省时沿用 `localStorage` 的 `desk.group`（否则平铺），并用 replace 把实际分组写进网址，分享后不受接收者的本地偏好影响。手动切分组仍更新此偏好。按主机时每列内卡片按负责人（无负责人则发布者）的 `host` 分组，组头一行 text-secondary 的主机名，人发布且无负责人的归「未指派」放最后；组内顺序不变。搜索输入写入网址 `q`，200ms 防抖后走 `GET /tasks?q=`（Query key `["tasks", q]`），匹配任务ID、标题、正文、结果；清空移除 `q`。

M37 任务ID搜索：现有协作台和历史页搜索框均可输入完整任务ID或连续片段，沿用原筛选、200ms防抖和结果打开方式；不新增按钮、ID徽标或搜索占位文案，不改变布局或密度。旧终态仍须到历史页选择对应状态搜索，完整ID命中也不自动打开详情；具体匹配规则见DESIGN §12.13。

M29 筛选网址（M30增加逾期）：协作台同时支持 `health=in_progress|silent|blocked|waiting|overdue`，无参数表示不加健康筛选；健康计数仍先按搜索作用域统计。搜索输入用 replace，分组和健康切换用 push，浏览器前进后退同步输入与结果；仅对读取数据的搜索保留200ms防抖，不允许旧计时器覆盖新网址。非法分组按平铺、非法健康值按无筛选解释，首次分组初始化或下一次筛选操作可规范化，其他未知参数原样保留。打开、关闭详情及点击依赖仅改 `task`，筛选不能清掉 `task`；刷新和直接访问带筛选的深链均有效。本轮不扩展历史页、活动页或传递区筛选。

M30 逾期筛选：健康筛选增加「逾期 / Overdue」及计数，只计搜索作用域内存在 `dueAt`、`dueAt < 当前时刻` 且状态非 `done`/`cancelled` 的任务；恰好到期、今天稍后到期和无截止时间不计。复用现有一分钟时钟更新，任务完成、取消或修改截止时间后随现有数据更新；不新增请求、通知或卡片徽标。与其他健康筛选单选，支持再次点击/全部清除、`health=overdue`刷新分享及前进后退，保留 `q`、`group`、`task` 和未知参数，viewer可用。

桌面（≥900px）沿用紧凑健康按钮，新增逾期使用既有警示色点和文字，不只依靠颜色。窄屏（<900px）将整组健康筛选替换为一个原生select，含「全部」和五项名称/计数，沿用现有表单样式和可访问名称；避免增加换行或隐藏在横滑末端，加载/错误计数仍为「… / —」。390宽筛选控件保持一行，页头不高于改动前，看板可用高度不减少；三皮肤浅深无页面横向溢出。桌面1440×900保持至少4张完整普通活跃卡/列，1000×600看板高度≥380px且页面不纵滚，卡片尺寸不改。

M31 清除筛选：协作台有非空搜索词或有效健康筛选时，在健康筛选行右侧显示紧凑文字按钮「清除筛选 / Clear filters」，一次清除 `q` 与 `health`，保留当前实际 `group`、本地分组偏好、打开的 `task` 和所有未知参数（含重复值）。这是一次离散操作，只新增一条浏览历史；后退恢复清除前搜索/健康组合，前进恢复清除结果，刷新一致。清除时立即取消旧搜索防抖效果并显示现有未筛选任务，不能等旧请求返回后重新显示旧结果；复用现有任务缓存，不新增接口、后台刷新或计时器；清除后原有卡片及健康查询仍按既有规则加载。健康控件的「全部 / All」仍只清健康筛选。

按钮在桌面与现有健康按钮同排，窄屏与原生select同排（select可收缩，按钮文字不换行），不新增页头行、不改变卡片或无匹配文案。无筛选时隐藏；点击后若按钮因此消失，焦点回到搜索框。管理员/viewer均可用；保留现有弹层焦点约束，不增加快捷键、命令面板或全站筛选框架。三皮肤浅深、中英、390×844及最挤的1000×600英文布局都不横溢；页头不高于M30同数据基线，看板可用高度不减少，桌面原密度要求沿用。

点击卡片右侧滑出详情抽屉（宽 480）：标题、状态与可用动作按钮、正文 markdown、负责人与发布者、能力、依赖、时间线（事件流，带 `report` 的进展说明）。管理员有编辑弹层，可改标题、正文、优先级、标签、能力、截止时间；截止时间按浏览器本地时间显示，非终态逾期加文字提示。动作按钮只显示状态机允许的。已指定任务增加「放回待领取」和「重新指派」，后者复用原来的选择接收者弹层；接收者已删除时这两个入口仍可恢复任务。按钮完成和拖到已完成都先打开同一成果说明弹层，允许留空，取消不发请求。

依赖一节：每行状态点 + 阻塞任务标题（点击切换抽屉到那个任务）+ 右侧 `×` 移除；末尾「添加依赖」展开一个搜索输入，按标题筛当前列表（排除自身与已依赖的），选中即 PATCH。没有依赖时只显示「添加依赖」。

发布弹层：支持可选本地截止日期时间，提交为 ISO；优先级下面一个分段「待领取 · 指定 · 招募」，选指定出现智能体 select（在线/离线两个 optgroup），选招募出现人数输入（默认 2），规则见 DESIGN §12.23。标题栏右侧一个「模板」文字按钮，打开 Menu 列出动作为 `publish_task` 的定时任务名（不论开关），选中后把 template 的标题、正文、优先级、标签、能力填进表单；一个都没有时不显示这个按钮。

拖拽：卡片可拖到任何合法列；拖到不合法列时该列标头变灰、放下无效并抖一下。从进行中拖到已指定会弹出交接弹层：选接收 AI（可不选）、写交接说明。

#### M41 从已有任务新建

管理员在已加载任务详情的底栏「更多」菜单中选择「从此任务新建 / Create from this task」，打开原发布弹层的可编辑草稿；协作台、历史页和传递区共用，所有任务状态均可用，viewer及角色未加载时不显示入口。保留原编辑按钮、主状态动作及其顺序；即使没有其他次要动作，更多菜单仍可承载此项。不新增底栏按钮、复制字段选择器或额外确认层，发布弹层标题、模板入口及样式保持原有设计。

只预填点击时的title、完整原始body、priority、tags、capabilities；不追加「副本」后缀或来源链接。截止时间为空、发布方式为待领取，指定对象为空、招募人数回默认2；发布人沿用正常发布的当前本地偏好，不继承源任务publisherId。依赖、状态、负责人、招募成员、租约、结果、事件、ID及创建/完成时间均不复制。标题/正文仍可编辑，长正文和Markdown不能从折叠DOM取值；标签未编辑时原数组完整保留（包括单个标签中的空格或逗号），编辑后按原分隔输入规则提交，选择模板后沿模板规则覆盖。没有来源时原空白发布不变。

打开草稿、取消、关闭或按Esc不写任务；只有显式发布走原POST /tasks和原校验、错误、pending及成功失效逻辑，服务端自动分派等规则不变。草稿打开后原任务实时变化不能覆盖正在编辑的内容；切换源任务或关闭详情后不保留旧草稿。取消和成功都只关闭发布弹层，回到仍打开的原任务并将焦点还给可见的更多按钮；原详情滚动、URL、筛选和历史位置保持，不自动跳新任务，不在浏览器存储或服务器保存草稿。打开时焦点在标题输入，底层详情不可交互，Esc只关闭最上层弹层，沿既有原生dialog，不扩全站弹层/焦点框架。

三皮肤浅深与中英共用原表单；390宽菜单和表单无页面横溢，长内容在原内容区滚动，取消和发布可达，不缩字、不加嵌套主滚动区。详情固定标题≤120px、正文可见区≥弹层一半的要求保持，原桌面标题/底栏/正文几何不变；关闭新草稿后仍可继续原编辑及主状态动作。仅验新增入口、预填/重置、取消/提交及代表界面，不重跑完整详情、状态机或办公室矩阵。

#### M23 任务详情阅读层级

固定标题最多两行，关闭按钮固定在标题右上且不被长文字挤动。标题超出两行时提供「查看完整标题」入口，在主滚动区顶部展开完整标题；展开不增高固定标题栏，可收起，键盘可操作。短标题不重复。390宽固定标题区（含入口）≤120px，主内容可见高度至少占弹层一半；切换任务或重开重置。长URL可换行，不能仅依赖hover/title属性查看全文。此规则仅用于任务详情，不扩改其他浮层。

保留480宽抽屉及三皮肤设计。内容按标题/状态、任务要求（body）、执行结果（result）、基本信息、依赖、进展记录排列。任务要求和执行结果有明确小标题，以间距及现有分隔线区分，不连成同一正文；未完成无结果显示「尚无执行结果」，已完成无结果显示「未填写执行结果」。保留Markdown与换行，长URL自动换行，超过6行的正文默认折叠，可展开全文/收起，不能丢失原文。

### 传递区 `/relay`

两栏。左栏是消息列表，按时间倒序，可搜索标题/正文并按收件对象、种类、关联任务、待答复/已答复筛；收件对象筛选增加「人」。服务端每页 50 条，「加载更多」取旧消息，切筛选重置。每行：种类小标（说明/成果/请求/回复）、发送者 → 收件对象（发给人的显示「我」）、标题、相对时间，人收件箱里未读的加粗。右栏独立读取完整可见线程，不受列表当前页限制：标题、发送者与收件对象、关联任务（可点开任务抽屉）、markdown 正文、谁已读（人读过显示「我」）；回复链以缩进线串起来，深层缩进最多六级但保留所有内容。管理员打开线程时，线程里发给人的未读消息逐条标读，成功后列表和侧栏未读数更新，失败不提示也不重试，下次打开再标。线程里每条消息的「回复」不预选收件对象，提交时省略 `to`，由服务端回给原发件人。右上「发消息」弹层：收件对象（指定 AI / 能力 / 全体 三选一，没有「人」）、种类、标题、正文、关联任务；关联任务输入搜索词后从候选项选择 ID，不把自由文本当 ID。这个页面给人看全部，也是人向 AI 发指令的地方；viewer 可查阅搜索和线程，看到相同的未读数，但打开不标读，隐藏发送/回复，n 快捷键不写入。
左栏顶部是三个分段：「收件箱 · 已发 · 全部」，对应人的 `box`（DESIGN §12.27）。默认打开收件箱，分段选择写进地址栏 `?box=`，刷新后保留；收件箱分段带未读数。切分段与切筛选一样重置分页。

侧栏的「传递区」入口右侧显示人收件箱的未读数（`GET /relay/summary` 的 unread，超过 99 显示 99+，为 0 不显示）；有待答复的请求时再加一个小点，悬停或读屏文字为「N 条请求待答复」。数字随 `relay.sent`、`relay.read` 实时更新。三套皮肤各用自己的徽标样式，不只靠颜色区分。

### 自动化 `/automation`

顶部按连接器分段（segmented control），右侧一个和协作台同款的搜索框，输入 200ms 防抖后在客户端按工作流名、项目名、触发方式过滤四列，清空恢复。每段四列：待执行 · 执行中 · 已完成 · 失败。待执行列是「仍在等待的实例 + 有在线定时的工作流的下一次执行」（规则见 DESIGN §12.21），工作流卡第三行写「下次 HH:mm」；已完成列只放成功（绿点）和已取消（灰点）；失败列红点加错误摘要。卡片：工作流名；第二行项目名（text-label text-text-2，没有则不显示这一行）；第三行触发方式、开始时间 → 结束时间、耗时，时间写 `HH:mm:ss`，不是当天的前面带 `MM-DD`，没结束的写 `→ …`，整行 title 是两个完整时间；右上外链图标。右上角「刷新」和上次轮询时间。连接器出错时列顶显示一条细红线和错误文字。

看板头部在搜索框左边加一个分段「今天 · 全部」，无网址参数时默认今天，不从 `localStorage` 恢复范围。今天只影响已完成和失败两列，只留当天的 run（规则见 DESIGN §12.29）；待执行和执行中两列不受影响。已完成和失败卡片右上外链图标左边一个隐藏按钮（lucide `EyeOff`，16px，text-3，悬停 text-2，aria-label 和 title「隐藏」），只有管理员看得到；点了立即从列里消失并失效查询，失败用 Toast 提示。隐藏的 run 默认不显示，列计数也不算。当前范围里有隐藏的 run 时，分段右边多一个文字按钮「已隐藏 N」，按下后隐藏的卡片以 60% 不透明度显示在原来的列里，隐藏按钮换成 `Eye`「取消隐藏」，再按一次「已隐藏 N」回到默认；这个开关不存储。viewer 也能看到「已隐藏 N」，但没有隐藏和取消隐藏按钮。搜索、范围、隐藏三者同时生效。

#### M23 自动化实例展示修正

自动化无网址参数时重新打开页面默认「今天」，不再从localStorage恢复旧的「全部」选择；可主动切到全部查看历史。今天仍按现有日期定义，只限制已完成/失败，不限制待执行/执行中。不要删除历史数据或取消全部入口。

M29 筛选网址：用 `connector=<ID>`、`q=<搜索词>`、`range=today|all` 保存现有筛选。合法网址参数优先，刷新、直接访问和前进后退均同步；缺省/非法 range 按今天，空搜索不保留参数。缺省或已删除的连接器在连接器列表成功加载后沿用第一个可用项，以 replace 写入实际 connector，不能在加载/失败阶段误改网址；无连接器时不发 runs/jobs 请求。搜索输入用 replace、数据筛选保留200ms防抖，连接器和范围切换用 push，每次只改本页拥有的参数、保留未知参数。隐藏开关仍只是本次页面临时状态，不写入网址；范围和连接器不会改变已有恢复失败判定或隐藏规则。

实例卡片第一行只展示工作流名称和原有操作。去掉时间行前的实例名称/重复名称以及所有触发方式代码（如SCHEDULER、START_PROCESS）；时间行只保留开始→结束和耗时，窄卡可自然换行，不挤出卡片。第二行实际为项目名（jobGroup）：与工作流名相同则隐藏，非重复项目名独立显示以区分项目，不与时间挤在一行。名称允许最多两行，完整值仍可查看，不使用一串重复省略号。三皮肤一致。

失败区隐藏已恢复的旧失败：同一连接器、项目、工作流的更新成功实例覆盖此前失败；取消、正在运行不算恢复，成功之后再次失败仍展示。按稳定工作流标识与实例开始时间判定新旧，不按名称合并，也不以旧实例较晚结束覆盖新失败；时间相同不得凭猜测覆盖。用于判定的成功记录不得受搜索、今天/全部或手动隐藏影响。卡片与列计数使用同一过滤结果，不修改实例状态或删除历史。若现有接口不足以完整判断，先提交接口方案给负责人。历史成功仍可在全部中查询。

验收含同工作流失败→成功、成功→失败、取消/执行中、跨日成功、手动隐藏成功、同名不同项目/连接器。1440×900保持既定自动化每屏至少20张总卡片密度（数据足够时），390宽无横向溢出，时间/操作不裁切。

#### M34 复制失败信息

### 智能体 `/agents`

表格：状态点、名称、kind、主机、能力、最近活跃、Webhook、行尾 `…` 菜单（轮换密钥、编辑、删除）。Webhook 只显示「已配置（已隐藏）」或「—」，编辑使用密码框和隐藏值保留提示。「编辑」复用新建弹层（kind 不可改，没有 key 那一步）；「删除」弹出确认弹层，一句话「删除后它的任务和历史保留，key 立即失效」，主按钮红色「删除」。行点击展开：画像一行四个数字（完成 · 7 天完成 · 交接 · 平均耗时；数字用 text-title，下面 text-secondary 标签，平均耗时用「3 小时 20 分」这种写法，没有则「—」）、当前任务、最近事件。右上「新建」弹层：填名称、kind、主机、能力、Webhook（可选），确定后展示一次 key，带复制按钮和「只显示这一次」。key 下面再放一个主按钮「复制接入消息」，复制一段可以直接发给智能体的文字（见下）。

智能体列表在类型筛选旁提供搜索框，按名称、主机、能力或ID的字面连续片段匹配；查询去首尾空白并忽略大小写，各字段及每项能力独立匹配，与类型筛选取交集，保持原列表顺序和头像。只过滤已加载列表，不新增接口、请求或防抖。网址q首值原样显示，kind首值仅现有类型有效，未知值按全部；初次和浏览器导航不改写网址。输入仅replace q，类型切换仅push kind，保留另一键、其他参数及重复值和hash；默认值移除，对当前相同值不导航。非空搜索右侧提供清空按钮（含纯空白），仅push移除q并归还输入焦点，当前类型不变。有效筛选无结果时显示「没有匹配的智能体」，不显示新建引导；真正空列表沿原行为。管理员和viewer均可搜索及阅读详情，写权限、详情方式和轮询不变。桌面同排、390宽最多两行且不横溢，不缩字或改变列表密度。

「轮换密钥」先确认旧密钥立即失效；成功后只在当前弹层显示新 key，同样带「复制接入消息」（消息末尾多一句「这是轮换后的新 key：重新 idesk login，然后重启接收器」），复制失败有明确提示。关闭后不再显示或查询；viewer 的智能体菜单禁用，相关弹层均受会话角色限制。

```

<key>
```

详情打开方式：小于 md 的窄屏，三种皮肤点击智能体名称或行都打开现有详情弹层，接收端、测试推送按钮和结果须完整可见；行尾操作菜单不触发详情。桌面 classic/cartoon 使用展开行，pixel 保留详情弹层。关闭详情后清除本次测试结果。

### 定时 `/schedules`

列表：名称、cron 人类可读（如「每天 09:00」）、动作摘要、上次/下次运行、开关。HTTP 动作摘要只显示方法和「已配置（已隐藏）」，不展示地址。运行中显示状态并禁用该项「立即执行」，其他定时仍可运行；「执行记录」抽屉展示最近最多 50 条开始/结束事件，按 runId 配对，显示开始、结果、耗时及安全错误。未完成且本进程不再运行的项标为中断。viewer 保留记录入口，隐藏新建/执行/编辑/删除并将开关显示为只读文字，n 快捷键也受角色限制。手机表格只在面板内横向滚动。新建用分段表单，三种动作三个 tab。「发布任务」tab 下一行 text-secondary 说明：「关闭开关的条目可在发布弹层当模板用」。HTTP 编辑显示隐藏标记，并说明「已隐藏的值保持不动即保留，输入新值可替换」。

### 服务器 `/servers`

侧栏在「定时」与「活动」之间加「服务器」（像素图标：两层机架 + 指示灯）。用户要一眼看清每台机器的负荷，并在几台之间切换。

- 页头：标题「服务器」，副标题「每 10 秒更新 · 上次上报 N 秒前」（离线时写「离线 · 最后上报 N 前」，状态红色）。右侧：幽灵按钮「管理」（菜单：重命名、轮换令牌、删除）、主按钮「添加服务器」。viewer 不显示这两个。
- 工具栏：左边服务器切换（分段，每项「状态点 + 名称」；超过 6 台改为下拉），右边时间范围分段「1 小时 / 6 小时 / 24 小时 / 7 天」。选中的服务器和范围写进 URL（`?server=&range=`），并记在 localStorage `servers.selected`、`servers.range`，默认第一台、1 小时。
- 概要行（一行，12px `--text-2`）：主机名 · 系统 · 内核 · CPU 型号 × N 核 · 已运行 3 天 4 小时。
- 四块指标卡（一行四列，中等宽度两列，手机单列）：CPU（大号百分比，下面「负载 0.07 / 0.05 / 0.00」）、内存（已用 / 总量 GiB + 百分比）、磁盘（各分区之和）、网络（↓ 接收 / ↑ 发送，自动换算 KB/s、MB/s）。前三块带一条用量条，≥ 80% 用 paused 色、≥ 90% 用 failed 色；每块卡底部一条当前范围的迷你走势线。
- 图表（两列网格，窄屏一列）：「CPU 使用率」（面积，0–100%）、「内存」（已用与交换两条线，纵轴上限为总内存）、「网络」（接收、发送两条线，纵轴自动取整到好读的刻度）、「各核与分区」（左边各核当前使用率的竖条，右边每个分区一条用量条）。
- 图表手写 SVG，不加图表库。横轴刻度落在本地整点（1 小时每 15 分钟、6 小时每 1 小时、24 小时每 4 小时、7 天每天 0 点；绘图区窄于 400px 时间隔加倍），≤ 24 小时显示 `HH:mm`，7 天显示 `MM-dd`，自己拼字符串，不随浏览器语言变化。纵轴 2–4 个间隔，刻度取整（字节按 1024 进位取 1/2/2.5/4/5 × 10ⁿ 的步长，如 0/4/8/12/16 GiB、0/250/500/750/1000 KiB/s），同一根轴用同一个单位，不写多余的 `.0`。SVG 按容器实际像素宽度 1:1 绘制，文字不随宽度拉伸。提示框时间：1 小时范围 `HH:mm:ss`，其他 `MM-dd HH:mm`。相邻两点间隔超过 2 个桶宽时断线，不连成直线。鼠标移到图上出一条竖线和提示（时间 + 各条线的值），键盘可用左右键移动。数据刷新不重放动画。
- 字节一律按 1024 进位（KiB、MiB、GiB），保留 1 位小数；百分比取整。
- 没有服务器：空状态便签「还没有服务器」+ 一句「在服务器上运行一条安装命令，就能在这里看到它的 CPU、内存和网络。」+ 主按钮「添加服务器」。服务器还没上报过：图表区显示「等待第一次上报」和安装命令。
- 添加服务器弹窗：第一步只填名称；创建后同一弹窗切到第二步，显示安装命令（含令牌，等宽字体，复制按钮）和「令牌只显示这一次」提示；IDesk 所在机器另给一条带 `IDESK_URL=http://127.0.0.1:3300` 的命令。轮换令牌同样先确认，再显示新命令。删除用危险确认，说明会删掉它的全部历史数据。

验收：1440×900 一屏内看到页头、工具栏、概要、四块指标卡和第一行两张图，页面只纵向滚动，没有局部滚动条；390 宽单列无横向滚动；三种皮肤浅深两色都清楚。

### 活动 `/activity`

一条时间线，按天分组，每条：时间、图标、一句话（「codex@mac-mini 领取了 修复登录页…」）。类型和智能体筛选先在服务端执行，每页 100 条，「加载更早记录」沿旧游标继续；切换筛选从第一页开始，显示加载、错误重试、空结果和全部加载完状态。每种事件都有一句人话（表见 DESIGN §12.17），任何时候都不显示 `connector.polled` 这类原始类型名。

活动记录带有 taskId 时，原任务标题或短ID是可聚焦的文字按钮，点击或按 Enter/Space 在本页打开共享任务详情；无 taskId 的记录仍为纯文本。入口保持原文字列、字号与间距，使用强调色和下划线区分，长标题在列内换行。活动页以首个 task 查询值（非空时）显示详情，缺失或空值不打开；本页打开/关闭仅以 replace 设置/移除 task，保留其余参数及重复值和 hash，刷新或直接链接可打开。关闭后保留本次页面筛选、已加载记录与阅读位置，并在原触发按钮仍存在时归还焦点。未在当前任务列表中的旧任务仍按完整ID读取，权限和缺失任务错误沿共享详情，不逐条预取详情或写入事件。

活动页筛选网址使用 type 和 agentId：type 首值为 task/relay/agent 时应用对应类型，缺失、空、all 或未知值按全部；agentId 首值缺失或空时为全部，其余原串直接用于服务端查询，不依赖智能体列表加载，也不忽略已删除或未知ID。当前ID不在选项中时，原选择器用该ID显示当前值，列表加载到对应项后沿原名称显示。初次、刷新与浏览器导航不改写网址；用户改变筛选仅 push 修改对应参数（默认值移除），保留另一个筛选、task、其它参数的重复值和 hash，重复选择当前有效值不新增历史。刷新、共享链接及前进后退恢复同一筛选，仍须原有登录权限；分页继续每页100条、切换筛选从第一页开始，网址不保存游标、页数或滚动。原任务详情开关仅 replace task，筛选不变时保留已加载记录与阅读位置；不增控件、查询接口或缓存。

### 设置 `/settings`

左侧二级导航：连接器、插件、接入信息。连接器页每个实例一张卡：图标、名称、地址、状态、上次轮询、`…`（编辑、测试、停用、删除）；轮询进行中时状态显示「同步中 3/20」（插件汇报的进度，没有总数时只写「同步中」），地址下面一条 2px 的 accent 进度线，页面每 2 秒刷新一次直到结束；「编辑」复用添加弹层，config 预填掩码值，没改的密钥原样保留；「添加连接器」弹层先选插件，再按该插件的 configSchema 顶层字段生成输入框，键名命中掩码正则的用密码框。插件页一行一个：名称、版本、种类、开关、重载；configSchema 有字段的插件行尾多一个「配置」，点击在行下展开和连接器弹层一样生成的表单（枚举字段用 select）加「保存」。

viewer 的发布、编辑、状态动作、依赖、消息发送/回复、智能体、连接器、插件与手动刷新入口隐藏或禁用，n 快捷键遵循同一角色。任务卡仍可点击阅读和触摸滚动，不绑定拖动；本地皮肤、语言、详情和复制仍可用。共用 `useSession`，角色未加载时不启用写操作。

中文，简短，动词开头。按钮：「发布」「领取」「交接」「暂停」「完成」。空状态：「还没有任务」+「发布一个」。错误直接说原因：「已暂停的任务不能完成，先恢复」。相对时间：刚刚、3 分钟前、昨天 14:20、10 月 3 日。

## 7. 外观皮肤

以上颜色、圆角、阴影及「不装饰」规则描述默认的「简洁」皮肤。「卡通文具」允许下述视觉差异；信息密度、布局、字阶、状态含义、清晰文案和操作流程仍共用。禁用 emoji 图标、外部字体、渐变/玻璃效果和成组飞入等规则继续适用。

- 设置二级导航增加「外观」，手机宽度下可换行。外观页用三个原生单选项显示「简洁」「卡通文具」「像素事务所」，每个带非业务数据的界面缩略示意。选中状态有明确文字或图形，不只靠颜色；支持键盘与焦点环。
- 卡通文具：暖纸色背景、深橄榄墨色轮廓、薄荷绿色交互色、圆润控件。关键面板、卡片和按钮可用小幅硬边偏移阴影，有轻微按压反馈；不用大面积立体效果或随机彩色卡片。
- 深色卡通使用深墨绿色背景和暖浅色文字，保留纸片轮廓。普通文字与背景对比至少 4.5:1；状态仍由状态点与文字解释，错误不能被装饰色淹没。
- 颜色、圆角、阴影都在已有 `tokens.css` 定义，通过根元素 `data-skin` 覆盖；页面复用原有组件。皮肤不改变列宽、任务排序、权限、实时状态或接口。
- 小型文具标志可以用于卡通侧栏和登录页，保持辅助地位。不要加入假头像、假统计、假徽章或营销文案。
- 动效 120–200ms；减少动态效果偏好下关闭。按压反馈不能覆盖拖拽使用的 transform。
- 页内说明：仅影响当前浏览器；浅色和深色跟随系统；像素办公室保持原有场景。切换即时生效，页面刷新和重新登录后仍保留。

## 8. 像素事务所（W89）

与像素办公室的插画属于同一个世界：丰富的木纹、厚实的家具边框、细密的像素轮廓、纸张与文具、植物和暖光。不得用低色数格子、统一粗描边或只换底色来替代这一质感。不限制美术色数或明暗层数；信息区仍以可读性为先。

- 基础材料色：深胡桃 `#3b271c`、栗木 `#805033`、蜂蜜木 `#bd824a`、灯光纸 `#f4e3bb`、墨字 `#352b23`、松绿 `#45604a`。浅色是午后工作室，深色是台灯下的夜间木柜与纸面；状态文字、焦点与错误提示须有足够对比，不用全屏滤镜实现夜色。
- 桌面左侧木柜导航，顶部木招牌与工具架，内容为内嵌工作面。协作台用软木任务墙与文件夹列；传递区用信件分拣槽与展开信纸；自动化用设备控制台与状态牌；智能体用档案册；定时用日程登记簿；活动用流水日志；设置用配置抽屉与册页；登录用前台接待构图。历史及空状态也保持对应材料，不回落到默认白卡。
- 丰富细节主要放在侧栏、页头、面板框和空白角落，正文背后使用安静的纸面。真实材质与道具图像可以生成或从项目原画加工；不能把一张整页效果图当界面，也不能只是原页面叠在办公室背景上。
- 品牌、导航、短标题与列头使用本地授权像素字体；长正文、输入与细小中文保持系统字体清晰度。像素字体避免假粗体与非整数缩放糊边；保留许可证，主网页不能依赖可选的 `/office` 静态资源。
- 装饰植物、书、台灯和笔筒不得阻挡点击、焦点或滚动，不进入无障碍树，不伪装成业务状态或在线人物。页面文字、计数、操作均为真实 DOM；不加营销文案和假统计。
- 保留布局密度和清楚的动作层级；该皮肤可调整框架与间距，但不复制业务逻辑或更改权限、任务状态、数据查询。简洁和卡通文具维持已有布局及外观。
- 原生表单、菜单、弹层、抽屉、危险确认、禁用与加载/错误态都覆盖，支持中文/英文、键盘、减少动态效果、200% 缩放和手机宽度。手机收拢装饰与导航，保留可见主动作和看板列选择器。
- 复用现有 token 系统，在 `pixel` 作用域定义材质及样式；适当拆分 CSS，避免影响其他皮肤。装饰资源按实际显示尺寸优化，非首屏大图按需加载，不引入新的 UI 框架。

### 8.1 页头收紧与侧栏小合影（W97；页头部分已被 8.2 取代）

- 页头不再单独占一条横景。`≥900px` 时，标题木牌、页头操作和横景合成一条高 72px 的「工作台条」：横景作底（`cover`，纵向取台面一带），左侧标题木牌（像素字 20px，内边距约 6px 16px），右侧原有操作。工作区内边距 16px，页头与下面的筛选条之间 10px，筛选条与看板之间 12px。窄于 900px 时条高 56px，横景两侧道具可以被裁掉，标题和主动作必须完整。
- 看板页（协作台、传递区、自动化）把高度留给展示区：1440×900 下看板列顶边离视口顶端不超过 170px（传递区筛选项多，允许换成两行，不超过 210px）；1000×600 下页面本身不出现滚动条，看板高度不少于 380px，卡片只在列内滚动。其他页面套用同样的页头，不留大片空白。
- 侧栏底部原来的「植物 + 书 + 台灯」道具图换成「智能体小合影」：一个木相框，框里是办公室一角（墙面和木地板）的小场景，三个智能体小人（用办公室同一批角色图集里的走路帧，外观固定挑三种不同 kind）在地板上来回走，各自速度和起点不同，走到边上转身，偶尔停下面朝观众站一会儿。`prefers-reduced-motion` 下三人并排面朝观众站着，就是一张合影。纯装饰：不带名字，不和在线人数或真实智能体挂钩，`aria-hidden`、不拦截点击；侧栏高度不够时整块隐藏，窄于 900px 不显示。所需帧和背景复制到 `apps/web/public/pixel-office/`，主网页不依赖 `/office` 的资源。

### 8.2 像素事务所第二版（W100–W102，取代 §8.1 的页头横景条）

用户评价第一版「粗糙、按钮位置不合理、不美观，像模板套皮」。根因：每一层都用木框、粗描边和投影来分层，框套框；导航每项是一个独立木盒；页头横景被裁成半截植物，标题、搜索、按钮挤在一条上；控件只是原生控件加了边。第二版按「游戏菜单 UI」的做法重做，可以改组件结构（JSX），不只是换 CSS；简洁、卡通文具两套皮肤的样子不变（改共享组件时用截图对比证明）。

**层级规则：一层一种材质，只有最外层有木框。**
1. 外框（应用框）：侧栏与内容区外沿是一整块连续木柜，木纹 `softer-wood`，内边缘一圈 2px 深色 `--ink` 线 + 2px 高光线。全应用只有这一处木框。
2. 桌面（内容区）：一整块暖纸面（`paper`），四角各一个小铜角（CSS 或小图，8×8），没有投影。页面所有内容直接放在纸面上。
3. 部件（卡片、列、列表、表单块）：扁平纸色，1px `--line-strong` 描线，最多 2px 底部实色阴影（`0 2px 0`），不再叠木框、不加外描边 outline。
4. 浮层（弹窗、抽屉、菜单、提示）：浅纸底 + 2px `--ink` 描线 + `4px 4px 0` 实色阴影，是除外框外唯一用粗线的地方。

**网格与尺寸。** 4px 网格；间距只用 4/8/12/16/24/32。控件高度：标准 32px，小号 28px，表单输入 36px。圆角 0（像素直角），用 1px 切角（`clip-path` 八边形）表现圆润，不用 border-radius。

**字体。** 像素字体只用 12px 或 24px（整数倍，避免糊边）：导航、按钮、列头、标签、页标题（24px）。正文、输入、表格内容用系统字体 14px，辅助信息 12px。中英文都要检查。

**按钮。** 统一一个组件四种变体，全站同一规格：
- 主按钮：松绿 `--accent` 底、灯光纸字，像素 12px，左上 2px 高光、右下 2px 暗边（像素斜面），按下时整体下移 2px、暗边消失。每个区域最多一个主按钮，放在该区域右上（页头）或右下（弹窗底栏）。
- 次按钮：纸底、`--ink` 字、同样的斜面。
- 幽灵按钮：无底无边，悬停出纸色底；用于「历史」「查看全部」这类次要链接式动作。
- 危险按钮：砖红底；只在确认弹窗里出现。
- 图标按钮：32×32 方形幽灵按钮，必须有读屏文字与悬停提示。
- 焦点：2px 松绿外框 + 2px 偏移，三种底色上都看得见。

**输入类。** 输入框、下拉、日期：内凹纸面（上、左 2px 暗边，下、右 1px 高光），36px 高，左内边距 12px，占位文字 `--text-3`；聚焦时边框变松绿。搜索框带 16px 放大镜图标。下拉和日期的箭头/日历图标统一画成像素图标，不露原生样式（原生控件的弹出层可以保留）。
**分段切换（Segmented）**：一条内凹槽，选中项是凸起的纸色按钮（像素斜面），未选项平放在槽里；同一工具栏里所有切换高度一致（32px）。
**开关（Switch）**：像素拨杆，开为松绿。

**图标。** 导航、按钮、状态用一套 16×16 像素图标（按像素格画的 SVG `<rect>`，1px = 1 格，两色：`currentColor` + 透明），替换 lucide 线条图标。至少覆盖：协作台、传递区、自动化、智能体、定时、活动、设置、办公室、搜索、加号、关闭、刷新、历史、筛选、更多、上/下箭头、勾、叉、暂停、播放、信封、齿轮、退出、语言、全屏。

**侧栏。**
- 顶部品牌：铜牌上的像素「IDesk」（24px），高 56px，不用旧的空白木招牌图。
- 导航：不是一个个木盒。每项 40px 高，左 16px 内边距：图标 + 像素 12px 文字，平放在木纹上（文字灯光纸色）。悬停：木色变浅一档。当前页：一张纸色「文件签」从右侧伸出、与内容区纸面连成一体（右边无描线），文字墨色，左侧一条 4px 松绿标记。徽标（未读数）是右侧小铜牌。去掉每项右侧的「—」。
- 小合影保留，放在导航与底栏之间，宽度与导航对齐。
- 底栏：一行 32px：在线状态（绿点 + 「3 在线」）在左；右侧两个图标按钮：语言（显示「中/EN」）、退出。只读访客的「只读」小标放在在线状态后。

**页头。** 去掉横景条。页头在纸面顶部，高 56px，底部一条 1px 虚线分隔：
- 左：页标题（像素 24px）+ 可选副标题（如「上次轮询 2 分钟前」，12px `--text-2`）。
- 右：动作区，从左到右「幽灵按钮们 → 次按钮 → 主按钮」，间距 8px。
- 筛选与搜索放在页头下面单独一条工具栏（高 40px，间距 8px）：左边搜索框（宽 240），然后各个分段切换，右侧放视图切换。工具栏和看板之间 12px。
- 横景插画改作侧栏顶部或空状态的装饰，不再出现在页头。

**看板（协作台、传递区列表、自动化）。**
- 列是一只纸托盘：浅一档纸色底、1px 内凹线；列头在托盘内顶部（像素 12px 列名 + 状态色小方块 + 数量小铜牌），不再是悬在上方的独立盒子。列宽最小 248px；放不下时横向滚动，滚动条画成像素样式，最后一列右侧留 16px，不能被截成半个字。
- 卡片是索引卡：纸色底、1px 描线、顶部 3px 状态色条、2px 底阴影；标题 14px 粗、元信息 12px；悬停上抬 1px，拖动时阴影加大。
- 空状态：列内只显示一行淡字「空」；整个看板没有数据时，在看板中央放一张「便签」：小插画（文具/植物）+ 一句说明 + 主按钮。

**列表与表格（智能体、定时、活动、连接器、历史）。** 放在一块纸卡里：表头 32px（像素 12px、`--text-2`）、行高 48px、行间 1px 虚线、悬停行底色加深一档；状态用像素小标（图标 + 文字 + 状态色描边）；行内动作是右对齐的图标按钮，主次清楚；空状态同看板便签。

**弹窗与抽屉。** 结构固定三段：头部（像素 24px 标题 + 右上图标关闭按钮，底部 1px 线）、可滚动正文、固定底栏（右对齐：取消=次按钮、确认=主按钮；危险操作用危险按钮）。主按钮永远可见，不会掉到折叠线下面。表单：标签在上（12px 像素字，必填带 `*`）、输入 36px、说明 12px；短字段两列排布；分组之间 24px。抽屉宽 480，内容同样三段。

**夜间（深色）。** 结构不变；木框变深胡桃，纸面变「台灯下的纸」（暖深灰褐，文字灯光纸色），高光与暗边相应调整；对比度：正文 ≥ 7:1，辅助文字 ≥ 4.5:1，状态色在两种底上都 ≥ 3:1。

**验收口径。** 「像游戏菜单而不是套了皮的后台」：每个页面在浅深两色下没有框套框；同类控件全站一致；动作位置符合上面的规则；1440×900、1000×600、390 宽三档无截断、无横向页面滚动。

### 8.3 服务器状态（W105）

像素皮肤下的服务器页像一台老式监控终端，但仍在纸面上：
- 指标卡是纸色部件（§8.2 第 3 层），用量条画成「血条」：一格 4px 宽、格间 1px 缝的方块条，填满的格子用状态色。
- CPU 图用竖条（每个桶一根，1px 缝），不用斜线；内存与网络用阶梯折线（只画水平和竖直线段，2px 粗，`shape-rendering: crispEdges`）。
- 坐标刻度用像素字 12px，网格线 1px 虚线 `--line-strong`。提示框是浮层（§8.2 第 4 层）。
- 线条颜色用令牌：`--chart-1`（CPU、接收）、`--chart-2`（内存、发送）、`--chart-3`（交换），三种皮肤各自定义，浅深两色下对纸面对比度 ≥ 3:1。
- 经典皮肤：1.5px 平滑线 + 极淡渐变面积，克制；卡通皮肤沿用卡通令牌的圆角和描边。


### 8.4 人员与助理（M25，W114–W118）

规则见 DESIGN §12.33。三套皮肤都用现有组件（简洁表单、卡通卡片、像素册页），不加新视觉元素。

**发布者显示。** 所有显示发布者的地方（卡片无负责人时、详情抽屉、历史、活动、办公室事件、传递区）：人员 id 显示人员名，`human` 显示「管理员」（英文 Admin），已删除的人员显示「已删除人员」。活动一句话带渠道：「张三 通过飞书 发布了 X」。`useAgents().agentName` 扩展为同时查人员，不另起一套。

**发布弹层。** 优先级上方加「发布人」select：第一项「管理员」，其后是 `role=member` 的人员；上次选择存 `localStorage` 的 `publish.person`（人员不存在时回到管理员）。没有人员时不显示这一行。

**设置 · 人员。** 二级导航在「插件」后加「人员」「助理」。人员页一个表格：名字、角色（成员 / 只读）、已绑定渠道（飞书/钉钉/企业微信小徽标，悬停显示平台昵称）、`…`（改名、改角色、生成绑定码、解绑某个渠道、删除）。表头右侧「添加人员」打开弹层：名字、角色。「生成绑定码」弹窗大字显示 6 位码和剩余分钟数，下面一句「在飞书、钉钉或企业微信里给 IDesk 机器人发：绑定 123456」带复制按钮；关掉弹窗不作废码。删除确认写明「已发布的任务保留，发布者会显示为已删除人员」。空状态：「还没有人员」+「添加一个」。
